## Original
As a user, I should be able to fill out a form that will allow me to report issues I am
having with the web application.

As a user, I should be able to view the magazines available, so I can decide if I want to 
read them or not.

As a user, I should be able to see when the next magazine issue will be released.

## Refine Enhancements
As a user, I should be able to click on an available magazine, and see product details for 
that magazine.

As a user, I should be able to subscribe to a newsletter to get the latest updates about
the magazine.

As a user, I should be able to subscribe to the magazine, ensuring that I will be able to purchase the magazine.
